# Ο κήπος των αισθήσεων — η σελίδα της Efthalia (Λία) Arnaoutopoulou

Στατική ιστοσελίδα-βιτρίνα για γεωπόνο / αρχιτέκτονα τοπίου, έτοιμη για **GitHub Pages** (χωρίς backend).
Δίγλωσση (Ελληνικά / Αγγλικά), με πίνακα διαχείρισης για δημοσίευση έργων & ιδεών, και ιδιωτική βιβλιοθήκη templates με κρυπτογράφηση.

## 🚀 Ανέβασμα στο GitHub Pages (μία φορά)

1. Φτιάξε λογαριασμό στο [github.com](https://github.com) (ιδανικά της Λίας).
2. Δημιούργησε **νέο repository**, π.χ. `efthalia-garden`. Κάν' το **Public**.
3. Ανέβασε όλα τα αρχεία αυτού του φακέλου στο repo
   (μέσω «Add file → Upload files» ή με git).
4. Πήγαινε **Settings → Pages**.
5. Στο «Build and deployment → Source» διάλεξε **Deploy from a branch**,
   branch `main`, φάκελος `/ (root)`, και πάτα **Save**.
6. Σε 1–2 λεπτά η σελίδα είναι ζωντανή στο
   `https://<το-όνομά-σου>.github.io/efthalia-garden/`

## 🔑 Σύνδεση στον πίνακα διαχείρισης (μόνο με κωδικό)

Η Λία μπαίνει στον πίνακα (`/admin.html`) **μόνο με έναν κωδικό**. Το κλειδί του GitHub
αποθηκεύεται μία φορά, **κρυπτογραφημένο με AES** και κλειδωμένο με τον κωδικό της, στο
αρχείο `data/auth.json`. Έτσι δεν χρειάζεται backend και κανείς δεν βλέπει το κλειδί χωρίς τον κωδικό.

### Βήμα 1 — Φτιάξε το κλειδί GitHub (μία φορά)

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access:** Only select repositories → διάλεξε το `efthalia-garden`.
3. **Permissions → Repository permissions → Contents:** `Read and write`.
4. Γέννησε το token (ξεκινά με `github_pat_…`) και αντίγραψέ το.

### Βήμα 2 — Ρύθμιση σύνδεσης (μία φορά)

1. Άνοιξε τη σελίδα `.../admin.html` και πάτα **«Ρύθμισε τη σύνδεση (μία φορά)»**.
2. Ο owner και το repository συμπληρώνονται αυτόματα από τη διεύθυνση (αν όχι, γράψ' τα).
3. Επικόλλησε το κλειδί GitHub και **όρισε τον κωδικό σου** (π.χ. `ZervLia!`).
4. Πάτα **«Ρύθμιση & αποθήκευση»**. Το κλειδί κρυπτογραφείται και αποθηκεύεται στο repo.

### Από εδώ και πέρα

Σε **οποιαδήποτε συσκευή**, η Λία ανοίγει το `admin.html`, γράφει τον κωδικό της και μπαίνει.
Τίποτε άλλο. (Στη δική της συσκευή μένει συνδεδεμένη μέχρι να πατήσει «Αποσύνδεση».)

> 🔐 Ο κωδικός δεν αποθηκεύεται πουθενά — χρησιμοποιείται μόνο για να ξεκλειδώσει το κλειδί.
> Αν αλλάξει το κλειδί GitHub, απλώς ξανακάνει τη «Ρύθμιση σύνδεσης» με νέο κλειδί.
> ⏱️ Μετά από κάθε δημοσίευση, το GitHub Pages χρειάζεται ~1 λεπτό για να δείξει την αλλαγή.

## 🔒 Ιδιωτικά templates (κρυπτογράφηση)

Επειδή το repo είναι δημόσιο, τα αρχεία των templates (Realtime Landscaping, PDF, κατόψεις)
**κρυπτογραφούνται με AES στον browser πριν ανέβουν**.

- Στον πίνακα διαχείρισης, στην καρτέλα **Templates**, η Λία διαλέγει template, ανεβάζει αρχείο και βάζει έναν **κωδικό κρυπτογράφησης**.
- Το αρχείο ανεβαίνει ως `.enc` — ακατάληπτο χωρίς τον κωδικό.
- Στη σελίδα `templates.html`, η Λία βάζει τον ίδιο κωδικό στο «Ξεκλείδωμα» και κατεβάζει τα αρχεία της αποκρυπτογραφημένα.
- Οποιοσδήποτε άλλος κατεβάσει το `.enc` βλέπει μόνο κρυπτογραφημένα δεδομένα.

> ⚠️ Κράτα τον κωδικό ασφαλή. Αν χαθεί, τα αρχεία **δεν** ανακτώνται — αυτό είναι το ζητούμενο.

## 📮 Φόρμα επικοινωνίας

Η φόρμα στέλνει μήνυμα στο email της Λίας χωρίς να εκτίθεται το email δημόσια:

1. Φτιάξε δωρεάν λογαριασμό στο [formspree.io](https://formspree.io) με το email `arnthalia@gmail.com`.
2. Δημιούργησε νέα φόρμα — θα πάρεις ένα endpoint `https://formspree.io/f/xxxxx`.
3. Άνοιξε το `assets/js/main.js` και αντικατέστησε τη γραμμή
   `formspree: "https://formspree.io/f/your_form_id"` με το δικό σου endpoint.

Μέχρι να ρυθμιστεί, η φόρμα δείχνει μήνυμα επιτυχίας χωρίς να στέλνει (demo mode).

## 🌍 Δικό της domain (προαιρετικό)

Αν αργότερα θέλει π.χ. `efthalia-gardens.gr`: αγόρασέ το από έναν registrar (~10–15 €/χρόνο),
και στο **Settings → Pages → Custom domain** βάλε το domain. Όλα τα υπόλοιπα παραμένουν δωρεάν.
